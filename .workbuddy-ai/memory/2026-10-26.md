## Assignment 3: Interactive Experience — Sound Canvas

Built a browser-based generative art canvas ("Sound Canvas — Paint with Sound") for a programming course assignment (due Nov 1, 2026).

### What was built
- Pure HTML/CSS/JS web app, zero dependencies
- Mouse/touch on canvas draws trails + plays pentatonic notes (Y=pitch, speed=volume)
- 3 brush modes: Glow (sine), Particle (triangle), Ribbon (sawtooth)
- Color maps to pitch: warm=high, cool=low (visual-audio synesthesia)
- Playback feature: replays all strokes in sequence as music
- Error handling: audio API fallback, touch events, note throttling
- Two-canvas architecture (main for strokes, overlay for particles)
- Git history with 4 logical commits
